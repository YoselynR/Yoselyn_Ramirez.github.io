True color image (RGB)

What is a True Color Image (Red Green Blue)?

A True Color Image is as it sounds, a visual representation of satellite data where the colors correspond to the red, green, and blue components of the light spectrum, the primary colors of light that the human eye can perceive. When combined, they form a full spectrum of visible colors, with the same idea in mind this is applied to remote sensing and geospatial analysis. Combining data from three specific bands of a satellite image or raster data, creates a true color image. The three bands as you can guess are red, green, and blue, and are very important to plotting the satellite data as you will see in the next few code chunks.

Bands summary

- Red Band (corresponds to the red light wavelength, similar to the human eye)

- Green Band (corresponds to the green light wavelength, similar to the human eye))

- Blue Band (corresponds to the blue light wavelength, similar to the human eye))

Importance of True Color Images for Analyzing Data:

True color images provide a realistic view of the Earth’s surface, a natural representation, similar to what we would see with our own eyes. This can be useful for quickly understanding the landscape, vegetation, water bodies, urban areas, and other natural features. Often true color image is necessary in determining the next spatial analysis to make. As for this analysis of the Thomas Fire, the areas affected by the fire need to be better visualized and so another type of satellite imagery is explored next.

Summary/Limitations of True Color Images:

  • Easy visual interpretation - land cover, as it looks similar to the naked eye.

  • Cannot See Non-visible Wavelengths - like infrared, which can be useful for vegetation health analysis.

  • Cloud Cover - special processing is needed, such are robust=True.

False color image

Why is it False?

A false color image is a type of image in which other electromagnetic spectrum colors are used to represent different features or properties of the landscape. The colors do not correspond to the colors normally seen with the naked eye. Similar to true color image, false color image needs infrared, short wave infrared, and near infrared bands to highlight specific features.

Bands Summary

  • Infrared (IR),
  • short-wave infrared (SWIR)
  • near-infrared (NIR)

Why false color imaging is important

  • Vegetation Analysis - as we will explore with the Thomas Fire

Next we will look at the Air Quality Index during the time of the Thomas Fire.

Air quality during and after fires is critically important for several reasons, as wildfires and even smaller fires can release a variety of harmful pollutants into the air, which pose serious health risks to humans and animals. During a wildfire, a number of harmful substances are released into the air. These pollutants can have immediate and long-term health impacts, particularly for vulnerable populations such as children, the elderly, and people with pre-existing health conditions. Wildfires can have a devastating impact on local ecosystems, and poor air quality during and after fires can harm vegetation and animal life.

import pandas as pd

Some information on a few useful libraries

  1. When working with datasets or results that are stored in different directories, os helps you manage file paths, allowing your code to be flexible and system-agnostic. For example, os.path.join() is used to create platform-independent file paths.

  2. As for rioxarray, this is an extension of the xarray library for handling geospatial raster data (like satellite imagery or other geospatial data formats). It leverages rasterio to read, write, and process raster files.

  3. For visualizations matplotlib.pyplot is one of the most commonly used libraries in Python for creating static, interactive, and animated plots and graphs as seen in this blog. In geospatial analysis, you can use plt.imshow() to visualize raster images (such as satellite imagery) and adjust color maps to highlight different features (e.g., vegetation or urban areas).

  4. Geospatial data, rasters and vectors, often require heavy manipulation and numpy enables efficient handling of large datasets. As well as performing manipulations on multi-dimensional arrays, which can be common in remote sensing.
